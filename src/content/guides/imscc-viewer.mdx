## Getting an export out of Canvas

In the course, go to **Settings → Export Course Content** and choose **Common Cartridge (.imscc)**. Canvas also writes
some extra files alongside the archive:

- **`course_settings/`** — the course settings, the modules, the assignment groups, the late policy, the rubrics, and the
  file list.
- **`wiki_content/`** — one HTML file per page.
- **`g<id>/`** — one folder per assignment, quiz, or discussion, holding the content and its settings.
- **`non_cc_assessments/`** — the questions for quizzes that use the standard QTI layout, and the item banks.
- **`web_resources/`** — the files the course owns.

The viewer accepts the `.imscc` archive, or the same archive renamed to `.zip`.

## How content is matched to modules

Canvas does not put module items directly into the export. A module item points at an _identifier_, and the manifest
records what that identifier means:

```text
module_meta.xml     module item  ──▶  identifier
imsmanifest.xml     <item identifierref>  ──▶  resource
imsmanifest.xml     <resource>  ──▶  the content file(s)
```

The viewer follows that chain. It does not rely on the module's own `identifierref`, because for external links Canvas
writes the item's own identifier there instead of the resource identifier — following it would leave every external link
unresolved.

## The QA report

The report groups findings into seven categories.

| Category                  | What it looks for                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Structure**             | Module items with no matching resource, content that is in the export but in no module, empty modules, hidden files |
| **Publish state**         | Unpublished modules and items, and locked modules                                                                   |
| **Content**               | Pages and assignments whose body is almost empty, and courses with no front page                                    |
| **Links & references**    | Links that leave the course, images hosted elsewhere, and references to the source Canvas instance                  |
| **Grading & submissions** | Assignment groups weighted 0%, assignments without a due date, a point value, or a place in the final grade         |
| **Quizzes**               | Access codes, quizzes with no questions, unlimited attempts, and lockdown browser                                   |
| **Course settings**       | Visibility and enrolment, hidden final grade, course licence, missing card image, and the late penalty              |

A finding lists the items it is about. Clicking one of them opens the item in the browse step.

### The three downloads

- **Report (Markdown)** — the course summary, every finding, and every module with its items.
- **Findings (CSV)** — one row per finding, with the severity, the category, and the notes.
- **Inventory (CSV)** — one row per item, with the module, the type, the state, the points, the size of the body, and the number of links.

## What the viewer does not do

- **It does not show Canvas' styling.** Course content is rendered as plain, readable prose. The text and the structure are
  preserved; the colours and the boxes are not.
- **It does not load images from other sites.** Images that are part of the export are shown. Images hosted elsewhere are
  reported instead, because showing them would send a request to a third party — and the page's content security policy
  blocks it anyway.
- **It does not follow links inside the export.** Links to other pages in the same course become jumps within the viewer.
  Links to files inside the export are listed. Links to the source Canvas instance are listed, not opened.
- **It does not change anything in Canvas.** The export is a snapshot; the viewer only reads it.

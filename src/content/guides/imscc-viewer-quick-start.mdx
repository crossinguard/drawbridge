---
title: "Canvas Course Export Viewer quick-start"
description: "Open a Canvas course export and see everything it contains."
toolSlug: "imscc-viewer"
kind: "quick-start"
---

1. **Export the course from Canvas.** In the course, go to **Settings → Export Course Content** and choose
   **Common Cartridge (.imscc)**. If you only have the file with a `.zip` extension, that works too — it is the same
   archive.
2. **Open it here.** Drop the file onto the drop zone, or use **Choose an archive**. An already-extracted course folder
   works as well, via **Choose an extracted folder**.
3. **Browse.** The outline on the left mirrors the modules. Switch to the **Table** view to see every item in one list,
   and use the **State** filter to show only unpublished items.
4. **Read the report.** Continue to the **QA report** for unpublished items, content that is not in any module, links that
   leave the course, and settings worth a second look. Download it as Markdown or CSV.

Nothing is uploaded. The export is read in your browser and forgotten when you close the tab.

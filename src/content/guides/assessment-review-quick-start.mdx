---
title: "Canvas Assessment Review quick-start"
description: "Turn a Canvas course export into a plain-text review you can hand to a colleague or an assistant."
toolSlug: "assessment-review"
kind: "quick-start"
---

1. **Export the course from Canvas.** In the course, go to **Settings → Export Course Content** and choose
   **Common Cartridge (.imscc)**. A file with a `.zip` extension works too — it is the same archive.
2. **Open it here.** Drop the file onto the drop zone, or use **Choose an archive**. The archive itself is what the
   tool reads.
3. **Review.** The **Overview** tab says what the course holds and what the review found. The other tabs break it
   down: modules, assessments, quizzes, rubrics, the gradebook, and every finding with the values it compared.
4. **Export.** Continue to the export step and download the review file. It is one plain-text file that holds every
   fact the tool read, with the file it came from, so it can be read by someone who cannot open the export.

Nothing is uploaded. The export is read in your browser and forgotten when you close the tab.

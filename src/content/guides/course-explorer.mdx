## What this tool helps you do

Course Explorer gives you a readable overview of a Canvas course export. You can see what the file contains, follow the course's module structure, search its content, and read individual items.

It only reads the export. It does not change the course in Canvas, grade or assess the course, or tell you whether something is a problem.

## What you need

You need a Canvas course export with an **.imscc** filename. The same archive renamed to **.zip** also works.

The export is a snapshot of the course. Some Canvas features and content may not be included in that snapshot.

## Getting an export from Canvas

1. Open the course in Canvas.
2. Go to **Settings → Export Course Content**.
3. Choose **Common Cartridge (.imscc)** and create the export.
4. When Canvas finishes, download the export file to your device.

You need permission to export the course. If you do not see this option, contact someone who manages the course.

## Open and explore the course

1. Select **Choose a course export**, or drop the file onto the import area.
2. Wait while Drawbridge reads the file. Large courses can take a little longer.
3. Review the course overview for a count of its modules, pages, assignments, quizzes, discussions, files, and rubrics.
4. Use **Modules** to follow the course structure, or **All content** to browse each unique item in the export.
5. Use the search and content-type filter to narrow the list.
6. Select an item to read its content and see the details included in the export.

An item can appear in more than one module. **All content** shows it once and its detail view lists every module it appears in.

## Understand what you see

- **Published**, **Unpublished**, and **Locked** describe the state recorded in the export. They are information, not warnings.
- **Not in a module** means the item is included in the export but is not placed in a module. It does not necessarily mean the item is unused.
- **Not included in this export** means Drawbridge cannot supply that detail from this file.
- **Import notes** explains files Drawbridge had to repair or could not read.

Course content is shown in a simplified, readable style rather than an exact copy of its Canvas appearance.

## Moving between tools and guides

You can open this guide and return to Course Explorer without losing the opened course. Future connected tools will use the same course session.

A browser refresh, a new tab, or **Close course** clears the opened file and everything Drawbridge read from it. After a refresh, choose the export again.

## Privacy

The export is processed entirely in your browser. It is not uploaded, saved to an account, or written to browser storage. Drawbridge does not load externally hosted images from the course, because doing so would contact another website.

The Drawbridge site itself is cached for offline use after its first load. That site cache does not contain your course export.

## Troubleshooting

### “This archive does not look like a Canvas course export”

Check that you chose the course's **.imscc** export, not a different Canvas report or an export from another tool.

### The export will not open

Try creating and downloading a fresh export from Canvas. If the file was interrupted during download, the replacement may work.

### Something from Canvas is missing

Canvas does not include every course feature or setting in an export. Course Explorer can only show what is present in the file. It cannot retrieve missing content from Canvas.

### Images or media do not appear

Files included in the export can be shown when Drawbridge supports them. Externally hosted images are not loaded. Embedded media and some external tools may appear only as links or not at all.

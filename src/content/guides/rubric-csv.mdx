## Expected table shape

The source table should have one row per criterion and one column per rating level. The first two columns are reserved:

1. **Criterion name**
2. **Points** — the maximum points for that criterion
3. **Rating columns** — one column per rating level, left to right from highest to lowest

## Supported import formats

- **Word .docx** — tables extracted directly from the document.
- **Rich paste from Word** — copy a table and paste it as HTML.
- **Markdown pipe table** — plain text with `|` delimiters.
- **Tab-separated text** — copied from a spreadsheet.
- **Canvas rubric CSV** — a CSV previously exported from this tool or from Canvas.

## Points presets

- **Full / Half / Zero / Zero** — First rating = full points, second = half (rounded), remaining ratings = 0.
- **Evenly spaced** — Points decrease evenly from full points down to 0.
- **Custom percentages** — Enter a percentage of the criterion points for each rating level.
- **Manual** — Every rating point is set by hand; presets do not change it.

## Output CSV format

The exported CSV follows the Canvas rubric import format: one row per criterion, with ratings flattened into repeating `Rating Name, Rating Description, Rating Points` triplets. Rows may be ragged when criteria have different numbers of ratings.

## Edge cases

- **Missing rating cells** — empty cells in a rating column are treated as skipped rating levels.
- **Different criteria, different counts** — some criteria may have fewer ratings than others. The tool preserves this when exporting.
- **Manual overrides** — points edited by hand are highlighted and kept when presets change until you reset them.

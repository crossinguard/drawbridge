1. **Prepare your data.** Create a table with columns `level`, `id`, and `text`. Optionally add a `mapsTo` column with comma-separated parent ids.

   ```
   level,id,text,mapsTo
   program,po1,Communicate effectively,
   course,co1,Write clear arguments,po1
   assessment,ao1,Thesis is clear,co1
   ```

2. **Load the outcomes.** Paste the table into the input area and click **Load outcomes**. Notes about any formatting issues appear below the input.
3. **Create mappings.** For each lower-level outcome, check the box next to the higher-level outcomes it supports. Program-level outcomes have no higher level to map to.
4. **Export.** Click **Continue to export**, then download the alignment table or the updated outcome list.
